# 🕵️ Fake Review Detection System

This project detects whether a product review is Fake or Real using Machine Learning.

## 📌 Features
- TF-IDF Vectorization
- Logistic Regression
- Random Forest
- SVM
- Streamlit UI

## 🛠 Tech Stack
- Python
- Scikit-learn
- NLTK
- Streamlit
- Google Colab

## ▶️ Run in Colab
Open notebook and run all cells sequentially.
